# Privacy

Memory-first means relevant memory actually exposed by the host, not all history or a
cross-provider memory bridge. The host's access, retention and provider processing rules
still apply. Local file storage does not mean data never reaches the selected AI provider.
This package has no telemetry or own server. It does not read mail/contact stores by default.

Preserve explicit scoped choices. No protected/sensitive trait inference for ranking.
Only job-relevant voluntary constraints/experience are used. Transfer prompts are
user-requested visible drafts with minimum relevant facts, not automatic uploads.
Research ledgers are private optional state, not user forms or public examples. A .gitignore
rule is not a privacy guarantee. Removal/correction requests apply through actual supported
host controls; do not promise deletions the host cannot confirm.
