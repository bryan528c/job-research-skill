job-research-skill 0.2.0-rc.2 실행 검증 후속 인계

이번 패키지는 2026-11-06 제공된 0.2.0-rc.1 최종 인계본을 실제 검사·수정한 개발 프리뷰다.
처음부터 다시 설계하거나 과거 ZIP을 요구하지 말고 현재 파일과 기록을 기준으로 이어가라.
이전 인계 전문은 docs/history/WORK_HANDOFF.rc1.ko.txt와 원본 main 이력에 보존되어 있다.

먼저 읽기:
README.md, docs/validation.md, docs/compatibility.ko.md, docs/github-readiness.ko.md,
docs/validation/runtime-cases.json, docs/release-checklist.md.

유지할 방향:
- 자연어 한 문장으로 시작. 현재 대화와 접근 가능한 관련 메모리를 먼저 이용.
- 판단을 바꾸는 부족한 개인 사실만 질문. 검색어·도구·기업군·산업·조사 방법은 자율.
- 고정 검색량·기업 수·추천 개수로 종료하지 않는다.
- 수집 누락, 잘못된 제외, 요약 중 누락을 각각 검수.
- 짧은 결과에 실제 공고·지원 링크, 핵심 근거·위험·다음 행동을 제공.
- 사용자가 선택한 공고만 현재 채팅 지원 준비 또는 새 채팅용 프롬프트로 이어간다.
- 후속 준비는 선택. 모든 공고의 인계 프롬프트를 자동 출력하지 않는다.

현재 완료 범위:
로컬 검사와 배포 재생성·무결성 검사를 실행했다. ChatGPT Work 개인 스킬 명시 로딩,
참고파일 읽기, 합성 메모리·웹 없음·저장 실패·선택 후속 동작, 실제 공개 웹조사 일부를 관찰했다.
기본 방식과 스킬의 고정 합성 공고 평가 결과는 동률이다. 검색 성능 개선을 주장하지 않는다.
64개 정의 시나리오 전체 실행과 다른 호스트 런타임은 not_run이다. 정확한 결과는 validation.md.

배포 및 후속 실무:
1. 소유자는 2026-11-06 RC 공개와 MIT 적용을 승인했다. 같은 승인을 다시 요청하지 않는다.
   대상: https://github.com/bryan528c/job-research-skill
   원격 원본은 archive/rc1-handoff, 검증본은 validation/0.2.0-rc.2에서 관리한다.
2. API로 기록한 원격 커밋과 원래 로컬 커밋 ID는 다르다. 원본 source tree는 대조했다.
   원본 ZIP과 Git bundle을 보존한다. 최신 원격 게시·PR·CI는 docs/github-readiness.ko.md에서 확인한다.
3. 필요 변경 후 python -m unittest discover -s tests -v,
   python scripts/build_release.py, python scripts/verify_release.py를 수행한다.
4. 추가 모델 평가는 정답과 과거 정답 노출 대화를 분리한 새 세션에서 수행하고 실제 도구 기록을 검토한다.
   실행 못한 호스트/사례는 not_run과 정확한 이유를 남긴다. RC/개발 프리뷰 표기를 유지한다.

실제 개인 메모리·이력서·메일·지원 결과·토큰·개인 도구 로그는 커밋하지 않는다.
현재 개인 채용 리서치 예약·알림을 변경하지 않는다. 계정 연결을 쓰기/로딩/검색/저장/예약 성공으로 추정하지 않는다.
완료 보고는 저장소/브랜치 또는 PR, 핵심 수정, 실제 검사 결과, 환경별 확인·미확인, 가장 쉬운 시작과 남은 승인만 짧게 쓴다.
