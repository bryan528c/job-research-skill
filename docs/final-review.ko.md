# 최종 검토와 반영 — v0.2.0-rc.1

## 기존 보완본 확인

0.1.1 ZIP의 18개 파일을 확인했고 기존 정적 검사 12개가 통과했다.
기존 검토 문서는 호스트 설치/메모리/저장/실제 채용 검색 품질이 미검증임을 명시했다.
따라서 과거 파일이 GPT·Claude·Gemini 어디서나 이미 검증됐다고 볼 수 없다.

## 이번 변경

1. 공통 Agent Skills 본체와 환경별 설치 경로를 분리했다. 업로드 ZIP 두 형태,
   OpenAI plugin 포장, CLI별 선택 설치, 단일 파일 대체판을 한 소스에서 생성한다.
2. 링크를 출처/공식직무/실제지원/홈페이지/대체경로로 구분한다. 토큰·실행 스킴·
   사설주소를 방어하고 역할·회차 확인을 요구한다. 링크 문법 검사는 실시간 검증이 아니다.
3. 선택한 공고만 같은 채팅에서 계획하거나 새 대화용 최소 프롬프트를 만들도록 했다.
   보고번호를 회차/직무 ID에 연결하며, 다른 AI의 메모리 자동 공유를 가정하지 않는다.
4. 누락을 수집·잘못된 제외·보고 누락으로 나눴다. 완료/반례검색/미탐색 기록 및
   후보-보고 일치 검사 코드를 추가했다. 증거 ID의 존재가 웹 열람의 진위를 증명하지 않는다.
5. 로컬 보조 설치기는 기본 미변경 계획만 출력하고 --apply에서 복사한다. 기존 파일
   덮어쓰기·자동 결제·원격 업로드·예약 변경은 하지 않는다.
6. 정적 검사 외에 실제 보조 코드 단위 테스트, 오프라인 합성 공고 fixture와 결과
   평가기를 추가했다. 모델 평가 시나리오 64건과 실제 모델 평가 결과는 구분한다.

## 남는 한계

어떤 프롬프트도 공개 웹의 모든 공고를 빠짐없이 찾았음을 증명하지 못한다.
검색 색인 지연, 비공개·로그인 공고, 계정 권한, 플랫폼 차단, 변경·조기종료,
모델의 도구 선택/분류 오류, 원문 오독 등이 남는다. 범위와 미확인 상태를 남기고
새 발견으로 드러난 영역을 재탐색하며 실제 host traces와 결과로 평가해야 한다.

이 패키지는 별도의 상용 백엔드가 아니라 호스트의 도구로 실행하는 스킬이다.
정적/보조코드 통과는 호스트가 지침을 지켰다는 보장이 아니다. 실제 GPT·Claude·
Gemini를 실행하지 않은 현재 상태는 RC/개발 프리뷰다. 검증 단계별 결과를 공개한다.

사용자 입출력은 자연어 한 문장과 짧은 링크 보고다. 내부 검사·원장·평가 자료는
일반 사용자에게 작성시키지 않는다. 현재 개인 예약/GitHub/메모리는 수정하지 않았다.
