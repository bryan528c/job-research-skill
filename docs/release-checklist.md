# Release gates

## Completed by this delivery

Canonical skill, host documentation, optional direct-link/selected-job workflow,
offline helpers, local installer, deterministic upload packages, synthetic fixture
sources, evaluator and local tests are present. See validation.md for actual execution.
No runtime host credentials or private user data are bundled.

## Runtime verification required before a compatibility claim

For each real host: record product/surface, version where visible, account policy constraints,
loaded skill version/hash, reference-file read, available web/memory/save capabilities,
observed role-specific link, selected-role continuation and real outcome. Do not copy
CLI success into Chat/Cowork/cloud/API success. Unknown/not_run is an acceptable honest state.
No-browser fallback must not claim current openings. No-memory fallback must not claim prior
context. No-store fallback must not claim future recall. A benign public read is not a save test.

## Research behavior evaluation

Run scenario definitions with the actual agent. Use the synthetic fixture browser, keep
oracle files out of the evaluated agent's view, retain an authorized private trace and
capture observable IDs/decisions/report mappings. The grader detects false exclusions,
missed known positives and report loss in this fixed corpus only. It is not a live search
benchmark. Live testing should use a dated accessible corpus reviewed independently.
Keep offline test fixtures/results separate from model run results and real job results.

## Publish only after owner decision

Approve destination/visibility/license; scan source, history, docs, images and release
archives for personal data/secrets; verify test and artifact hashes; include source and
installation guide; label tested host versions and limitations; confirm remote commit.
GitHub upload is not marketplace publishing and neither proves active scheduler rollout.
The owner approved public RC visibility and MIT on 2026-11-06; LICENSE is applied. No public data store for real users.

## No redesign loop

Do not ask the user to redesign the product again. Work from this contract, fix concrete
failures and finish feasible tests. Batch necessary owner decisions, name exact blockers,
and deliver useful artifacts even when a particular host/account is unavailable.
