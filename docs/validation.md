## 실제 모델과 도구 실행

정답·이전 답변이 들어 있는 부모 대화를 넘기지 않는 새 Work 세션 9개와 같은 대화의 선택 후속 1회를 실행했다. 상세 결과는 [runtime-cases.json](validation/runtime-cases.json)에 있다. 기존 64개 시나리오 정의 전체 실행 수는 **0**이며, 이 선택 사례들을 64개 통과로 바꾸지 않았다.

| 실행 | 관찰한 결과 |
|---|---|
| 고정 합성 공고: 기본 방식 / 스킬 방식 | 두 방식 모두 정답 추천 9/9, 잘못된 제외 0, 추천의 보고 누락 0. 검색 성능 향상은 입증되지 않음 |
| 명시 스킬 호출 | 실제 저장된 Work 스킬과 참고파일을 새 세션에서 읽음. 자동 선택·ZIP 업로드 UI는 미검증 |
| 같은 채팅에서 선택 공고 준비 | 보고 1번을 j01로 유지, 실제 출처 재열람, 기존 보고 보존. 문항/글자수/제출을 만들지 않음 |
| 한 파일 대체 + 선택 인계 | portable만 읽고 한 공고 인계. 제공 URL과 현재 열람을 구분, 날짜만 있는 마감 유지 |
| 저장 실패 | 지정 /proc 경로에 실제 1회 쓰기 시도, FileNotFoundError(errno 2). 현재 결과를 제공하고 장기 저장 성공을 주장하지 않음 |
| 합성 메모리 불충분 / 명시 정보 충분 | 최신 인턴 수용 정정과 입사일 제약을 각각 유지. 부족한 영어 요건만 질문하거나 명시된 불가 근거로 제외 |
| 메모리·웹 없음 | 현재 공고를 만들지 않고 직무/경험/지역의 핵심 정보만 요청 |
| 실제 웹 조사 2회 | 합성 인물로 한 회사의 공식 목록·직무·지원 경로를 실제 검색/열람. 각 10회 web 도구 반환 객체를 확인. 시장 전체 성능 측정 아님 |
| 보고 간결성 | **partial**. 지침 보완 후 새 웹 세션도 제외 공고 표와 긴 설명을 남김. 짧은 출력의 일관성은 남은 한계 |

첫 메모리 충분 사례의 `not available` 필드는 정보 없음과 능력 없음이 모호하여 **inconclusive**로 남겼다. 답을 가르친 같은 세션을 재사용하지 않고 명시적 사용자 사실을 넣은 새 세션을 실행했다.

평가자는 최종 보고의 링크/판정과 실제 search/open/inventory JSONL을 대조한 뒤 별도 oracle로 채점했다. 기본 방식 47회, 스킬 방식 56회 출처 명령은 관찰된 실행량이며 종료 목표가 아니다. 최초 보고 길이는 2,794자와 1,876자였고 후속 준비 요청은 이 비교에서 제외했다. 이 비교는 마지막 보고 참고지침 보완 전의 rc.2 실행이다.

합성 실행 폴더에는 정답을 복사하지 않았다. 다만 모든 에이전트가 공유 파일시스템을 쓰므로 보안 샌드박스 수준의 접근 차단은 아니다. 도구 출력 해시는 호스트 서명이나 전체 시장 조사 증거가 아니다. [합성 실행 증거](validation/synthetic/skill/score.json), [실제 웹 기록 인덱스](validation/public-web-index.json).

실제 계정 메모리·이력서·메일·지원 결과는 사용하거나 배포하지 않았다. 웹 도구 원문은 작업환경에서 확인하고 소스 배포에 포함하지 않았다. 개인 스킬 저장과 로컬 산출물 재읽기는 조사 상태의 장기 저장·예약 전달과 구분한다.

## 호스트 미실행 및 GitHub 상태

호스트별 상세는 [compatibility.ko.md](compatibility.ko.md). ChatGPT Chat/GPT, Codex CLI·Desktop·IDE, Claude 채팅·Cowork·Code, Gemini 앱·CLI 및 API는 **not_run**이며 이유를 각 행에 기록했다. 실제 계정 장기기억·조사 상태의 새 세션 복원·예약·알림 전달도 not_run이다.

GitHub 인증을 완료하고 승인된 개인 공개 저장소를 만들었다. 원본 소스의 실제 tree/commit/branch 쓰기와 VERSION 재읽기를 확인했다. 원본 tree 해시는 로컬과 동일하다. 다른 저장소에 시험 쓰기를 하지 않았다. 검증 브랜치·PR·CI의 최신 결과는 [배포 기록](github-readiness.ko.md)에 구분한다.

소유자가 2026-11-06 RC 공개와 MIT 적용을 승인했다. MIT를 적용했으며 원격 게시 성공과는 구분한다. 기존 개인 채용 리서치 예약·알림은 조회하거나 변경하지 않았다.
