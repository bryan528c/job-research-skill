## 완료 표시 원칙

공식 문서에 맞춘 파일 구성을 ‘문서 기반 호환’, 실제 파일 검사를 ‘로컬 통과’로 표시한다.
실제 호스트에서 확인 전에는 ‘모든 환경 정상 작동’이라고 쓰지 않는다.
새 버전을 문서에 적은 것, 설치 디렉터리에 복사한 것, 런타임에 로드한 것, 도구가
정상 실행한 것, 상태가 저장된 것과 알림이 전달된 것은 각각 별도 증거가 필요하다.
