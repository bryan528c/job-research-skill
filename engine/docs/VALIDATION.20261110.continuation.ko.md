## 해결한 오류와 지속 상태

- 목록 카드는 기존 상세·관측 시각·사용자 결정을 지우거나 새 상세 재검증으로 둔갑시키지 않는다.
  실제 카드 변경은 별도 증거로 저장하고 공채 자식 직무까지 재검수 전 추천을 막는다.
- 서로 다른 URL이 같은 바이트/시각을 갖는 실자료에서 존재하지 않는 observation ID가 반환되던
  제약을 schema3으로 수정했다. 기존 ID·BLOB·외래키와 백업을 보존하는 이관 회귀를 실행했다.
- Ninehire의 게시물 비노출·과거 closedAt·현재 canSubmit은 다른 신호다. 상시 마감과 실제 접수
  시작을 보존하며 텍스트 주변 원격/inline 이미지·iframe은 호스트 판독까지 pending이다.
- JobKorea의 관측 iframe과 공개 HTML의 inert JSON/UTF8 byte-text를 해석한다. JS eval이나
  숨은 인증 API를 쓰지 않는다. 실제 저장 desktop15개·mobile1개 계약을 현 코드로 대조했다.
  원문 판독과 정상 UI에서 확인한 모집 상태·지원 경로는 별도 증거다.
- 현대차 실제 공개 DOM을 개별 제목·업무·필수·우대로 분리한다. 직접 public GET 경로는 실제
  HTTP400이어서 네이티브 성공으로 부르지 않는다. 정상 브라우저로 확인한 상세는 별도다.
- 법인 충돌31개를 실제 공식 조회/공시/기업 자료로 검토했다.4개는 독립 출처로 입증한 가역 보정,
  나머지27개는 미확정이다. 역사적 승계/인수·관계사 설명만으로 법인번호를 합치지 않는다.
- 오래된 후보·결정·보고 번호·원관측·작업 나이를 DB와 대조했다. 수집·잘못된 제외·보고 요약
  누락을 나눠 감사하며, 검토 과정의 경력/영어 오판과 개인 공백을 source gap으로 숨긴 판정을
  정정했다. 직무 추천은 실제 핵심업무의 개인 근거를 요구하고 상용 매출/운영 경험을 만들지 않는다.
- 실제 UTC 마감을 보고 시간대로 변환하되 초·밀리초를 보존한다. date-only에는 시각을 붙이지
  않는다. KST 오전/날짜 경계와 접수 시작 전 상태는 별도 회귀다.

## 검증 상태

엔진/기존 root 테스트, 빌드·해시·격리 실행, 합성 규모/변이, 실제 사이트·호스트 AI 판독,
새 프로세스 복원은 다른 검증이다. 로컬/원격 최종 결과는 PR #2의 최신 검증 결과와 대응한다.
합성1만 기업·250공고의 재개 및 의도적 오류4종 탐지를 다시 통과했다. 이는 실제 조사량이 아니다.

로컬 Python3.13 엔진263개가 통과했다. 기존 root100개는96개 통과·4개 not_run이며 이
Windows 계정의 symlink 생성 권한(WinError1314)이 이유다. 네이티브 ZIP 격리 추출/실행은
root 검사에 포함된다. 현 코드로 실자료를 적용하기 전 복사 DB에서 적재·분해·판정을 검증했다.
실제 비공개 DB의 새 Python 프로세스에서 run·후보·결정·원래 작업 나이·접수 시작 시각·출처
설정·alias/식별자 보정·검토 원장·보고 번호의 전체 상태 해시가 동일했다. 이는 새 AI 채팅이나
다른 호스트의 실행 증명이 아니다. 실제 추천·중요 확인 전부와 별도 보존 후보를 보고 ID 원장과
대조해 누락0건을 확인했으며, 이전 사용자 보고의 번호는 다시 부여하지 않았다.

이전 검증 중 환경 임시폴더 권한 실패는 작업 폴더의 임시 경로로 다시 실행했다. 이를 기능
실패나 통과로 합산하지 않는다. 실제 긴 이미지 자산 내보내기에서 과도한 지연도 발생했으므로
빠른 자동 이미지 수집을 지원한다고 주장하지 않는다. 남은 판독 작업은 pending으로 보존했다.

## not_run / 중요한 미완료

- 전국 전체 집단·중견·계열사·독립 채널과 모든 개별 지원 경로, 남은 이미지·미평가 후보.
- OpenDART/고용24 키 필요 경로: 키 미설정. 공개 무키 경로는 별도로 실제 실행했다.
- Wanted 인증 출처: 현재 지원 준비가 선택되지 않은 단계여서 자동 승인 검토가 접근을 거절했다.
  인증·로그인·재시도·우회·개인 입력은 없었다. 공개 공고와 별도 공식 채널은 계속 조사했다.
- 독립 시장 holdout/모델 비교, 타 AI 호스트: not_run. 실제 현재 호스트의 원문/개인 근거 대조와 다름.
- 예약·알림 전달, 설치 스킬 교체, main 병합, 정식 release, 지원 준비·제출·기업 연락: 수행하지 않음.
  접수 시각의 not_before 작업은 재실행 시점의 큐이며 새 예약이나 서버가 아니다.
