## 분모·법인·과거 후보

네 공식 명부130,200개 출처 ID는 고유 기업 또는 조사 완료 기업 수가 아니다.
`universe-audit`의 registry/industry/group 페이지로 관측 귀속·미확정 채널을 대조한다.
법인 ID가 미확정인 그룹·ATS 관측은 별도이며 그룹 목록을 모든 계열사의 법인 검수로
확장하지 않는다. 미분류 업종과 명부 겹침이 남는다.

DART 새 정상 export119,967행→119,912출처ID를 적재했다. 중단된 단일 export를 다음
페이지로 중복 적재하는 경로를 차단했다. 영문 종목코드74개를 실제 복구해 공식 식별자
alias9,297개를 보존했다(영문 코드74개 복구와 별도 공식 식별자 bridge3개). 공식 공홈 footer와
공정위/DART의 동일 사업자·법인번호도 실제 대조해 관측 회사2개를 연결했다. 전체 component의 식별자 충돌/순환을 검사했다. 논리 충돌31개는
미확정이며 export 중복 ledger 행 수와 구분한다. 이름·브랜드·부서만으로 법인을 합치지 않는다.

원래154개 공고ID와 과거60개 원본을 보존했다. 실제 출처/동일 회차/원주소 bridge로19개

서로 다르다. 같은 외부 링크가 다른 포스터/채용범위를 가리키는 실제 반례는 동일 공고로
자동 합치지 않고 route-only 충돌로 보존한다.

## 실제 판단·보고와 코드 검증

호스트 AI가 실제 개별 본문·필수/우대·이미지와 최소 관련 개인 근거를 비교했다. 혼합 공채,
전문 개발/연구, 비즈니스 영어·협상 중심, 2026년 필수 출근은 각각 판단했다. 프로젝트를
상용 운영·매출·전문 분석 경력으로 만들지 않는다. 추가 명시 조건만 profile에 보강했고
기존 개인 사실은 보존했다. 기존 제외403건은 동일 본문/개인 사실의 검증된 충돌이 새 좁은
범위로 해소되지 않음을 대조해 근거를 재사용했다. 새 전체 원문 판독403건으로 세지 않는다.

중요 확인과 원문 공백·미래 Pool을 별도 report_tier로 저장한다. 추천은 숨김 tier를 허용하지
않는다. 보고 저장은 표시할 추천/확인 ID와 별도 보존 gap ID를 각각 대조한다. 이전 보고와
번호 매핑은 덮어쓰지 않는다. 모집/적합/사용자 결정/지원 진행도 별도 상태다.

root 테스트, engine 전체 테스트, 합성 규모/변이, 빌드·해시·격리 실행, 실사이트, 실제 AI,
세션 복원을 별도로 기록한다. 합성1만 기업은 실제 전국 조사량이 아니다. 최종 commit의
원격 Python3.10/3.13×Windows/Linux CI는 PR #2 Actions 실제 결과가 기준이다.

실자료에서 드러난 회귀는 공통 자격 누락, 나중 페이지 null total, 이미지 재검수/lease 차단,
오래된 관측 시각 보존, 개별 회사/근무지/지원 CTA, 빈칸 후속 직무행, 본문이 사라진 종료
공채의 자식 상태 전달, KST 오전 날짜/date-only 마감, 추천/보존 gap 보고 누락 방지다.

캠페인 목록 재확인에서 파생된 세부직무를 별도 목록 누락으로 오인하지 않도록 수정했다.
부모가 실제로 사라지면 부모 재검수 작업을 남기고 자식 상태/개인 결정을 자동 변경하지 않는다.

최종 로컬 Python3.13.14 engine205개가 통과했다. root100개는96개 통과·4개 미실행으로,
이 Windows 계정의 심볼릭 링크 생성 권한(WinError1314)이 이유다. 해당 사례는 원격 Linux
CI에서 별도로 실행한다. 합성1만 기업·250공고의 재개 시험과 의도적 오류4종 탐지도 통과했다.
이 결과는 실제 조사 기업 수·개인 추천 결과·모델 성능 비교를 대신하지 않는다.

## not_run / 미완료

- 전국 모든 그룹·중견·계열사·독립 ATS/플랫폼과 법인/지원 경로는 미완료다. 미탐색·차단·
  원문/이미지 공백은 원래 생성일과 함께 다음 실행으로 이어간다.
- OpenDART/고용24 인증 경로는 키 미설정으로 not_run이다. 키 없는 경로는 실제 실행했다.
- 동등 기간/자원의 baseline·rc.2·engine 비교와 독립 시장 holdout은 not_run이다.
- Claude/Gemini/채팅 전용 호스트·MCP 실행은 not_run이다. 현재 PC 실행과 구분한다.
- 한국시간 오전 정기 예약/알림 전달은 not_run이다. 기존 예약 변경이 금지되어 있고 타이머를
  만들지 않았다. 오전 날짜 변환은 실행 가능한 회귀로 별도 검사한다.
- 지원 준비/제출/기업 연락은 사용자 공고 선택 전 not_run이다.
- main 병합·정식 release·기존 설치 스킬 교체는 수행하지 않는다.
