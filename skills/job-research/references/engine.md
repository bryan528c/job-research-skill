# Durable research engine integration (engineering alpha)

Use for broad discovery or repeated research when an authorized execution host and private state
are available. This augments, not replaces, coverage.md, memory.md, links.md and reporting.md.
The engine is an internal implementation detail. Never ask ordinary users to fill JSON, manage
SQLite, create API keys or choose every source. Use relevant memory and ask only consequential
missing personal facts. No fixed query/company/recommendation quota.

## Actual activation

Read engine/README.md and engine/docs/HOST_INTEGRATION.ko.md in the repository. Verify the command
is executable and the private DB readable/writable. Use its real version and run ID, not a version
mentioned in a prompt. Native development packages include the same Python runtime under
scripts/runtime; the checkout uses engine/. Invoke `python scripts/research.py --db <private-path>`
from this skill directory, or bind JOB_RESEARCH_DB in the authorized host. A portable Markdown
attachment has no executable runtime. Never overwrite an existing installation to activate it.
When unavailable, say the current execution is instruction-only if this affects breadth/continuity;
do not silently claim durable or nationwide engine execution.

## Research loop

Establish a versioned employer universe with source boundaries and unknown coverage. Import the
full available source snapshot rather than a handpicked shortlist. Company categories must be
supported, not inferred from listing status. Sources unknown for companies produce discovery tasks.
Use enterprise inventories, platform discovery and adaptive duty/title searches in parallel where
capabilities permit. Native adapters and host browser exports are complementary routes.

Resume the incomplete run and cursor first while protecting urgent live opportunities. Keep oldest
gaps visible internally. Source failures do not erase candidates. A first-page hit is not an exhausted
inventory. Bulk campaign entries need individual roles. Key-dependent sources may be blocked while
public sources/host research continue. Respect source access policies; do not bypass restrictions.

Use `session <profile-id> "<natural request>"` to restore the incomplete run; `--new-cycle` explicitly
creates a repeat with all earlier candidates. Use `sync-registry krx|dart-web|ftc|mme --allow-network`
to acquire actual official snapshots, resuming page checkpoints. `reconcile-companies` links only
shared official identifiers and retains reversible evidence. Review counts as source records, never
as a national unique-company census. MME certificates may have been cancelled.

Use `discover`, `collect --details`, `recheck-legacy` and paged `packet` for actual work. Supply
`--allow-network` only on authorized read paths. Page sizes are context windows, not stop targets.
The one allowlisted SK form uses read-only POST search; no application POST is implemented.
Image-only descriptions require real host inspection through `capture-detail`; campaigns require
`split-job` with observed individual role sections before recommendations.

Resolve host/blocked/legacy tasks with actual tools, and send evidence-linked
assessments only after matching dominant duties to relevant user experience. The engine does not
supply or authenticate LLM judgment. Do not report an assessment as original employer fact.

Recheck uncertain exclusions through a materially different route. A new promising role expands
the exposed branch; record real follow-through. Execute coverage and candidate→report reconciliation.
Resource limits leave checkpoints and gaps, not a smaller denominator or fabricated completion.

## Output and optional continuation

Use a concise linked report. Internal counters, logs and IDs are not default user output, but retain
material limitations and all worthwhile opportunities. Preserve the report ID→number→job mapping.
After user selection only, refresh the role and continue in chat or produce a self-contained brief.
Never automatically submit, message employers, publish private data or change schedules.
